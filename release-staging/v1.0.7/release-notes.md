## مسبحتي 1.0.7 — ضبط التعرف على الكلام أثناء الصمت

إصدار صيانة لتحسين المزايا الحالية دون إضافة أقسام أو تعديل التصميم:

- تقليل تحديثات النصوص الصوتية المبدئية المتكررة دون داعٍ.
- منع نص مبدئي مكرر من إعادة ضبط مؤقت الصمت عندما لا يُرصد كلام جديد.
- التعامل مع اختلاف التشكيل والمسافات في النص العربي حتى لا تُعتبر كتابة العبارة نفسها كلامًا جديدًا.
- إعادة ضبط مراقبة النصوص المبدئية عند كل طلب استماع جديد؛ تكرار الذكر الحقيقي في الطلب التالي يظل مقبولًا.
- الإبقاء على قواعد احتساب النتائج النهائية والأذكار الطويلة بلا تغيير.
- اختبارات آلية إضافية للحالات السابقة.

يجب تثبيت التحديث فوق النسخة الحالية بنفس شهادة التوقيع الأصلية. موافقة Android مطلوبة للتثبيت. دقة التعرف الصوتي تعتمد على المحرك والجهاز، ولا يغني فحص GitHub الآلي عن اختبار هاتف فعلي.
