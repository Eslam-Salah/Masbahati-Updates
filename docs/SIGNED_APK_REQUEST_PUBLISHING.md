# مسار نشر مسبحتي عبر المستودع العام — دون صلاحيات كتابة عبر المستودعين

## الهيكل

مسار النشر المستقر: `.github/workflows/publish-signed-request.yml`.

يعمل تلقائيًا عند تحديث `release-requests/current.json` في فرع `main` في المستودع العام، ويستخدم `GITHUB_TOKEN` الخاص بالمستودع العام لإنشاء GitHub Release، **دون الحاجة إلى منح مستودع الكود الخاص صلاحية كتابة للمستودع العام**.

يقوم المسار بما يلي:

1. التأكد من تنسيق الإصدار ورقم البناء وبصمة SHA-256 وهوية الحزمة وشهادة التوقيع المتوقعة.
2. إذا كان الإصدار منشورًا بالفعل، يتحقق من بصمة APK وملف التحقق، ثم ينتهي بنجاح دون استبدال أي ملف.
3. للإصدار الجديد فقط، ينزل أرشيفًا مؤقتًا يحتوي على `Masbahati-<version>.apk` و`Masbahati-<version>.apk.sha256` لا غير.
4. يتحقق من حجم APK وبصمته، ثم شهادة التوقيع الأصلية باستخدام `apksigner`، واسم الحزمة ورقم الإصدار باستخدام `aapt`.
5. ينشر ملف APK وملف SHA-256 على صفحة GitHub Releases، ويتحقق من بصمة APK المنشور.

## أين تأتي طلبات النشر؟

يتم الحصول على APK الموقّع من المستودع الخاص `Eslam-Salah/Masbahati-Android`. يستخرج من GitHub Actions كأرشيف ZIP موقّع ومقيد التحميل، ثم تُسجل بياناته وعنوان تسليمه المؤقت في `release-requests/current.json` **بواسطة أداة GitHub المتصلة بصلاحية المستخدم، أو عملية نشر مخوّلة أخرى**.

ذلك لا يعني أن المستودع الخاص يستطيع تلقائيًا الكتابة في المستودع العام. إن لم تتوافر عملية مخوّلة لتحديث ملف الطلب، يلزم إجراء تسليم نسخة موقّعة لكل إصدار؛ لا تخلط بين التشغيل التلقائي بعد تسليم الطلب وبين التسليم التلقائي من المستودع الخاص.

## متطلبات السلامة

- لا يُرفع مفتاح التوقيع أو كلمات المرور إلى المستودع العام.
- عنوان التسليم المؤقت يمنح تنزيل **الأرشيف الذي يحتوي على APK وملف التحقق فقط**؛ لا تستخدم رابطًا لأرشيف مفتاح التوقيع.
- لا تنشر نسخة مختلفة تحت Tag موجود، ولا تخفّض رقم البناء.
- يجب أن تطابق شهادة APK شهادة النسخة الأصلية ذات SHA-256:
  `9182b5af8ff3e6464b959608f33f4b37c5f6e885cd7dae9c88c23821d1288159`.
- رابط التسليم قصير الصلاحية؛ إذا انتهت صلاحيته قبل التشغيل، يُستخرج رابط جديد من Artifact الأصلي ويُحدّث ملف الطلب.
- تأكد من نجاح اختبارات المصدر قبل طلب النشر؛ هذا المسار يتحقق من سلامة الملف والتوقيع لكنه لا يستبدل اختبار وظائف التطبيق على جهاز فعلي.
